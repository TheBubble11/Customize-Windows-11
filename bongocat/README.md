# BongoCat

My customized BongoCat setup for Windows 11.

## Features
- Custom Live2D model
- Overlay scale: 65%
- Opacity: 100%
- Maximum FPS: 60
- Always on top
- Click-through overlay
- Auto-hide on pointer hover
- Auto-hide after 10 seconds of inactivity
- Keyboard and gamepad input support

See [Configuration](configs/README.md) for complete settings and shortcuts.
